# MMO RPG — 자바 에디션 (Fabric 모드)

베드락 애드온 **MMO RPG 시스템** (v2.27.0) 을 마인크래프트 **자바 에디션 26.3 (Fabric)** 으로 옮기는 모드입니다 (1.21.1 판은 따로 보관 — 아래 설치).
밸런스 수치와 공식은 애드온에서 그대로 가져온 규칙 코어 (`core/`) 를 씁니다 — 애드온 JS 와 같은 입력 28,530개에서 같은 값이 나오는 것을 매 빌드마다 확인합니다.

## 지금 들어 있는 것 (1 · 2 · 3단계)

| 기능 | 내용 |
|---|---|
| 스탯 | 힘 · 민첩 · 마력 · 체력. 처음 접속하면 포인트 5 + 스탯 책, 경험치 레벨이 처음 오를 때마다 포인트 +3 |
| 스탯 창 | 키 **K** · 스탯 책 사용 · `/stats`. 줄을 누르면 +1 (Shift +5). 스탯마다 효과, 가진 무기 기준 실제 피해 |
| RPG 체력 | 최대 체력 = 20 + 최고 레벨 × 2 + 체력 스탯 × 1. 회복은 최대 체력 비율 (바닐라 회복 1 = 최대 체력의 1/20). 배고픔 없음 |
| 체력 바 | 하트 대신 애드온과 같은 체력 바 (숫자 · 25% 아래 깜박임 · 깎인 부분 잔상), 방어 · 레벨 · 남은 포인트 칸 |
| 무기 151종 | 칼 · 단검 · 도끼 · 방패 · 활 · 완드 · 마검, 등급 일반 ~ 초월. 요구 레벨 · 요구 스탯, 평타 = 공격력 × 스탯 배율 × 치명타 |
| 활 · 완드 | 누르거나 몹을 치면 바라보는 대상에 명중 (조준 보정 12°). 활은 빛줄기, 완드는 마법진 0.5초 뒤 마법 피해 |
| 방패 | 오른손에 들면 피해 감소, 웅크리면 앞에서 오는 공격을 막음 |
| 피해 숫자 | 맞은 대상 머리 위에 떠오르는 숫자 (평타 흰색 · 치명타 금색 ! · 플레이어가 받은 피해 빨강) |
| 무기 3D 모델 | 애드온 디자인 31종을 그대로 (손에 들면 3D, 인벤토리 · 땅 · 액자는 아이콘). 3인칭 자세는 애드온 화면과 같은 자리, 1인칭은 칼 · 단검 · 도끼 · 창 · 마검 · 완드를 세워 들고 베는 날은 앞을 향함 (완드는 장식 면이 화면 쪽, 활 · 방패는 애드온 그대로), 빛나는 칸은 밤에도 밝음 |
| 활 · 완드 이펙트 | 애드온 그림 그대로: 활 빛줄기 · 지나간 자리 · 맞힘 불꽃, 완드 마법진 10단계 (0.5초 동안 그려짐) · 쏠 때 번쩍임 |
| 근접 참격 | 칼 초승달 (좌우 번갈아) · 단검 X자 · 도끼 내려찍기 + 발밑 충격파 · 방패 고리 + 폭발 · 궁니르 찌르기 · 마검 + 룬 베기, 치명타 연출, 영웅 · 초월 기운, 허공 휘두르기도 |
| 무기 빛 알갱이 | 영웅 · 초월 디자인 13종: 무기에서 계속 떠오르는 색 알갱이 (애드온과 같은 자리 · 색 · 움직임 — 1인칭 · 3인칭 · 다른 사람 · 마네킹) |
| 화면 흔들림 | 도끼 · 방패로 맞히면 화면이 살짝 흔들림 (치명타는 더 크게) |
| 초월 무기 스킬 14종 | 초월 무기 7종마다 스킬 2개 (그람 · 솔라스 · 궁니르 · 아이기스 · 아르테미스 · 오딘 · 티르빙). 근접: 우클릭 = 스킬 1 · 웅크리고 우클릭 = 스킬 2, 활 · 완드: 웅크리고 우클릭 = 스킬 1 · 길게 누르기 = 스킬 2 · 짧게 = 평타. 요구 스탯 · 재사용 대기 (화면 하단), 스킬 피해 숫자는 하늘색 |
| 룬 80종 | 계열 16 × 등급 5 (일반 ~ 초월). 핫바에 두고 우클릭으로 사용 (요구 스탯 없음), 재사용 대기는 핫바 아이콘에도. 위력 = 레벨 기본값 × (1 + 적용 스탯 × 2%), 룬 피해 숫자는 노랑 (마력은 보라) |
| 룬 뽑기 | 룬 뽑기권 · 고급 룬 뽑기권 (일반 없음): 눈앞 마법진 연출 뒤 지급, 영웅부터 모두에게 알림. 연출 중에 나가면 다시 들어올 때 지급 |
| 초월 룬 연출 | 하늘빛 (둘레 사람의 하늘 · 먼 곳이 룬의 색으로) · 화면 번쩍임 · 하늘 · 땅의 영역 문양 |

2단계에서 1단계의 임시 표현 (바닐라 파티클 · 평면 무기 그림) 을 모두 애드온 그림 · 모델로 바꿨습니다. 남은 차이:
- 이펙트는 서버가 보내므로 누른 뒤 1~2틱 (0.05~0.1초) 늦게 보일 수 있음 (서버가 멀수록 더)
- 빛 알갱이 자리는 쉬는 자세 기준 (휘두르는 동안의 팔 움직임은 따라가지 않음 — 알갱이는 세계에 남아 떠오르므로 차이가 작음)
- 화면 흔들림 세기는 어림값 (세기 1 ≈ 10°, 베드락은 수치를 밝히지 않음)

3단계 (스킬 · 룬) 의 자바 판 차이:
- 룬 칸을 고르기만 해도 쓰기 (애드온의 터치 조작) 는 자바에 터치가 없어 기본 꺼짐 — `/runequick on` 으로 켬
- 하늘빛은 베드락 `/fog` 대신 클라이언트가 안개 거리 · 색을 바꿈 (모드가 없는 클라이언트는 보이지 않음)

아직 없는 것: 갑옷 · 강화 · 상점 · NPC · 퀘스트 · 룬술사 (4단계), 몬스터 · 보스 (5단계), 결투 · 탈것 (6단계). 계획은 `PLAN.md`.

## 설치

1. [Fabric Loader](https://fabricmc.net/use/) (0.19.5 이상) 를 마인크래프트 **26.3** 에 설치
2. [Fabric API](https://modrinth.com/mod/fabric-api) (26.3 용, 0.162.0 이상) 와 이 모드 jar 를 `mods` 폴더에
3. 모드 jar: 이 저장소의 **Releases → latest** (main 에 올릴 때마다 모든 시험을 통과하면 자동으로 새로 만들어짐)

마인크래프트 **1.21.1** 용 (1단계까지, 더 고치지 않음): **Releases → release-mc-1.21.1** (`mc-1.21.1` 브랜치, Fabric API 0.116.x+1.21.1).

서버에 넣으면 서버 · 클라이언트 둘 다 필요합니다 (모드가 없는 클라이언트도 접속은 되며, 스탯 창이 채팅으로 나옵니다).

## 명령어

| 명령어 | 권한 | 내용 |
|---|---|---|
| `/stats` | 모두 | 스탯 창 |
| `/rpg info` | 모두 | 스탯 · 체력 · 기준 무기 |
| `/rpg spend str 1` | 모두 | 포인트 투자 (str · dex · int · vit) |
| `/weapon sword 10 rare` | 관리자 | 무기 받기 (종류 sword · dagger · axe · shield · bow · wand · greatsword, 등급 common · rare · noble · hero · transcend) |
| `/points 5` | 관리자 | 스탯 포인트 |
| `/heal` | 관리자 | 체력 회복 |
| `/rpg reset` · `/rpg set str 20` · `/rpg book` | 관리자 | 스탯 초기화 · 스탯 값 정하기 (시험용) · 스탯 책 |
| `/rune axe hero` | 관리자 | 룬 받기 (계열 str · dex · vit · int · axe · bow · holy · storm · assassin · blade · spellblade · element · spirit · gravity · body · strike) |
| `/runeticket 10 [advanced]` | 관리자 | 룬 뽑기권 받기 (advanced = 고급 룬 뽑기권) |
| `/runequick auto\|on\|off` | 모두 | 룬 칸을 고르면 바로 사용 (자바에서는 on 일 때만) |

## 빌드 (GitHub Actions)

`main` 에 올리면 자동으로: Fabric 버전 확인 → 규칙 코어 대조 시험 → 모드 빌드 → 게임 시험 (서버) → 화면 시험 (클라이언트, xvfb) → 모두 통과하면 Releases 의 `latest` 에 jar.
각 단계 로그와 화면 시험 사진은 `ci-logs` 브랜치에 올라갑니다 (`SUMMARY.txt` · `ERRORS.txt` · 단계별 로그 · `client-checks.txt` · `shots/`).

직접 빌드: JDK 25 + Node 22 가 있는 PC 에서 `./check-core.sh && ./gradlew build` (build 가 서버 게임 시험을 함께 돌림), 화면 시험은 `./gradlew runClientGameTest`.
